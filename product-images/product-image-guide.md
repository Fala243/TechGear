To replace a photo, save the new file here with **exactly** the same name (all lowercase; GitHub Pages is case-sensitive), or change the `image` path for that product in `techgear-main.js`.

## Category placeholders

The four category placeholders below are SVG drawings:

- `laptop-placeholder-image.svg`
- `headphones-placeholder-image.svg`
- `smartwatch-placeholder-image.svg`
- `accessory-placeholder-image.svg`

A card shows its category's placeholder when a product has no photo of its own (for example, products added with the form), or when a photo file is missing.

### Tips

- Use the **4:3 landscape** shape (e.g. 1600×1200).
- Keep each file under about 300 KB (WebP at about 80% quality works well).
- Only use images you have the right to use, and that don't include real brand logos.
